# Автоматизация и парсинг e-commerce каталога John Deere

Готовый к использованию Python-скрипт (веб-скрейпер), разработанный для автоматического сбора данных динамического каталога с официальной платформы John Deere.

🚀 Демонстрация и результаты
• Обработанный и заполненный каталог: WestAgro - Каталог John Deere
• Профиль разработчика в LinkedIn: Матвей Кирильчик

🎯 Обзор проекта
• Задача: Автоматизировать сбор масштабного каталога запасных частей для сельскохозяйственной техники (включая наименования, точные артикулы/SKU, технические спецификации и изображения в высоком разрешении).
• Решение: Разработан кастомный Python-скрипт для безопасного извлечения данных о товарах с веб-сайта поставщика, очистки сырых данных и их форматирования в готовые шаблоны Excel для e-commerce.
• Результат: Рутинная задача по ручному копированию данных, занимавшая несколько недель, автоматизирована в эффективный рабочий процесс, выполняемый за несколько дней.

🛠️ Стек технологий и продвинутые возможности
• Язык программирования: Python
• Библиотеки: BeautifulSoup4, Requests, Selenium (для обработки динамического рендеринга JavaScript и бесконечной прокрутки страниц)
• Автоматизация данных: OpenPyXL (для глубокой очистки данных и структурированного форматирования файлов Excel)
